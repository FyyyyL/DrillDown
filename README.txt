五、月度数据的处理办法
本次保持旧包的声明可用日规则，避免只改截止日时同时悄悄改模型信息集。
1. 基础做法：按公布/可用日期做as-of对齐，在下一次发布前forward fill最近已知值。
2. reference_date保留实际所属月份，available_date记录本包何时允许使用。is_carried_forward=1表示沿用，age_days与is_new_release可一起提供给模型。
3. 抓到“9月数据在10月更新”不等于抓到“10月数据”。原频率仍为月度，重复填充不增加独立样本数量。
4. 若能逐项核实官方实际发布日期，可另行将估计可用日替换为真实发布日期。此次没有把所有估计时刻冒称为已验证首发时刻。
5. 若希望月内输入变化，可另建nowcast：仅用当时已知日周变量预测当月月度量，保留actual/nowcast标记，滚动样本外验证。未来外生变量也应由训练期内模型预测或采用最后已知值基线。
6. 更完整的方法是MIDAS、混频VAR或状态空间模型。普通日度VAR里重复月度水平并不会制造新的月度信息。
7. 不用未来月末实际值回填整个月，不用跨越未来发布日期的双向线性插值，不填0，不把预测值写成真实观测。

六、日期上限与公布滞后

例如EIA截至10/23周的库存于10/28公布，可保留在原频率源表中，但没有进入10/23 08:00的模型输入。10/23模型输入最新EIA周度参考期为10/16。
CFTC最新参考日10/20，在10/23下午发布，也未提前进入10/23 08:00输入。钻机10/23报告同理。
WTI目标10/23为109.72美元/桶，按原信息时点规则10/23 08:00已知价仍来自10/21，为103.95美元/桶。目标与已知输入文件用途不同。
